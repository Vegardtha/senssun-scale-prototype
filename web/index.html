      Limitations

      • Web Bluetooth works in Chromium browsers (Chrome, Edge) on desktop and Android. Firefox and Safari do not support it.
      • The page must be a secure context (this server uses http://localhost), and scanning must start from a click.
      • The computer needs a working Bluetooth LE adapter. The Android emulator cannot reach a physical scale.
      • Only services listed in the request are visible. Some UUIDs (for example the TI OAD service F000FFC0) are blocked by the browser.
      • Advertisement payloads (used by Senssun "broadcast" scales) are not available through the standard picker.
      • Close Movinglife on your phone first: many scales accept only one connection.
      • Decoded values follow the legacy Senssun frame layout from the Movinglife APK and have not yet been checked against a real capture.
